# Smart Attendance Management System

**Mini Project – Python Programming**

## Project Description
The Smart Attendance Management System is a beginner-friendly Python project designed to manage student attendance digitally.

It allows users to register students, mark attendance, view student details and generate attendance reports.

## Objectives
- To maintain student attendance records.
- To reduce manual attendance work.
- To calculate student attendance percentages.
- To provide an easy-to-use attendance system.

## Features
1. Add new students.
2. Mark students as Present or Absent.
3. View registered students.
4. Generate attendance reports.
5. Calculate attendance percentages.

## Technologies Used
- Programming Language: Python
- Data Structures: Lists and Dictionaries
- Concepts: Loops, Conditional Statements and Nested Loops

## How to Run
1. Install Python.
2. Download `smart_attendance.py`.
3. Open a terminal in the downloaded file's folder.
4. Run:

```bash
python smart_attendance.py
```
